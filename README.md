# Chronic Kidney Disease Classification Using SVM

## About the Project

This project focuses on classifying Chronic Kidney Disease (CKD) stages using the Support Vector Machine (SVM) algorithm with Grid Search optimization.

## Objective

The objective of this project is to develop a machine learning model that can classify CKD stages based on patient health data.

## Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Support Vector Machine (SVM)
* Grid Search
* Google Colab
* Flask

## Methodology

The project consists of several stages:

1. Data preprocessing
2. Data cleaning
3. Feature preparation
4. Data scaling
5. SVM classification
6. Hyperparameter optimization using Grid Search
7. Model evaluation
8. Flask deployment

## Model Performance

The optimized SVM model achieved an accuracy of approximately 98%.

## Deployment

The trained model was deployed using Flask to create a simple web-based prediction application.
